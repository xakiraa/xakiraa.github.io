# Aprende ocarina

## ▶ [Abrir la herramienta](https://xakiraa.github.io/notasocarina/)

Practica las notas de tu ocarina de 12 agujeros (La – Fa, 21 notas):

- Ves la nota en el pentagrama, su nombre y la posición de los dedos.
- El afinador escucha tu ocarina por el micrófono del dispositivo.
- Si mantienes la nota afinada 5 segundos, pasa a la siguiente (aleatoria).

Todo funciona en tu navegador: el audio no se envía a ningún servidor.
Al abrirla, el navegador te pedirá permiso para usar el micrófono.
